MyCycle Privacy Policy

Last updated: 4 November 2026

1. Information We Collect

MyCycle may collect names, email addresses, account credentials, period dates, symptoms, moods, personal notes and uploaded images.

2. How We Use Information

Information is used to provide cycle tracking, display cycle history, calculate estimated predictions and improve application functionality.

3. Data Storage

MyCycle uses backend services, Microsoft Azure Blob Storage and Azure Cosmos DB to store relevant application information.

4. Data Security

We use password protection and security measures to help protect user information. Passwords should be stored securely.

5. Data Sharing

We do not sell personal information. Information may be processed by service providers needed to operate the application.

6. Data Deletion

Users can contact the development team to request account and personal data deletion.
